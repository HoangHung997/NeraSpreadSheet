# Gói chạy thử và SDK

[Tải các gói tại Check out](../README.md#tải-về).
Gói app self-contained khác với NuGet SDK: người chạy thử chọn gói theo hệ điều hành;
người tích hợp SDK chọn Nera-SDK-packages.zip và dùng local NuGet feed.
Không phát hành lên nuget.org trong workflow này. Kiểm SHA256 và source SHA trước nghiệm thu.
