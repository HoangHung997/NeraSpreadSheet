# Security Policy

## Báo cáo lỗ hổng

Không đăng token, file khách hàng, workbook thật, Machine ID, đường dẫn người dùng hoặc thông tin broker lên issue công khai.

Khi tạo support bundle hoặc test fixture phải loại bỏ:

- access token, API key và credential;
- tên người dùng và đường dẫn máy cá nhân;
- workbook, sheet, cell và ID nhạy cảm;
- thông tin thiết bị có thể nhận dạng.

Repository chưa có kênh disclosure riêng. Trong giai đoạn bootstrap, chủ repository chịu trách nhiệm tiếp nhận báo cáo riêng tư qua GitHub Security Advisories khi chức năng đó được bật.
